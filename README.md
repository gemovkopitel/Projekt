# Task Manager
## Opis projektu
Task manager dla lokalneko korzystowania, dla zapisywania zadań i nei zapomonanie ich
## Cel projektu
Celem jest przejście od teorii do praktyki oraz zrozumienie, jak poszczególne elementy systemu webowego współdziałają jako spójna całościowa aplikacja.
## Funkcjonalności
- dodawanie zadań,
- edycja zadań,
- zmiana statusu,
- wyszukiwanie i filtrowanie.
## Technologie
- frontend: Projektowanie interfejsu (Frontend)
- backend: Budowanie logiki biznesowej (Backend)
- baza danych: Zarządzanie bazami danych PostgreSQL
## Struktura projektu
```text 
frontend/ 
backend/ 
database/ 
docs/
tests/ 
```
